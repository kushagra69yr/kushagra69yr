## 🚀 Featured Projects

### ⚡ CodeVector — High-Performance Product Catalog Engine

A production-oriented backend project focused on **fast, stable pagination over large and frequently changing product datasets**.

**What I built:**
- Cursor-based pagination instead of deep `OFFSET` scans
- Stable `(created_at, id)` ordering
- Composite/B-Tree indexing for efficient database seeks
- REST APIs using FastAPI and SQLAlchemy
- Performance benchmarking and concurrency testing
- Dataset scale of **200K+ products** in the project benchmark

**Stack:** `Python` `FastAPI` `SQLAlchemy` `PostgreSQL` `SQLite` `B-Tree Indexes`

[**Live Demo ↗**](https://kushagra6922-codevector.hf.space) · [**Source Code ↗**](https://github.com/kushagra69yr/codevector)
